# 🐧 Linux Mint — Linux Learning & System Administration

## 📌 Project Overview

This repository documents my experience learning and using **Linux Mint** as a Linux operating system. The goal of this project is to build practical skills in Linux administration, networking, security, troubleshooting, and command-line usage.

## 🎯 Learning Goals

* Learn essential Linux terminal commands
* Understand Linux file systems and permissions
* Manage users and groups
* Install and manage software packages
* Configure networking
* Learn basic Bash scripting
* Monitor system performance
* Practice Linux troubleshooting
* Learn basic cybersecurity concepts
* Document useful commands and solutions

## 💻 Environment

**Operating System:** Linux Mint
**Desktop Environment:** Cinnamon
**Shell:** Bash
**Architecture:** x86_64

## 🛠️ Topics Covered

### 1. Linux Terminal

Practice commands such as:

```bash
pwd
ls
cd
mkdir
touch
cp
mv
rm
cat
grep
find
```

### 2. System Administration

```bash
sudo apt update
sudo apt upgrade
systemctl status
df -h
free -h
top
```

### 3. File Permissions

Learn how to view and modify permissions:

```bash
ls -la
chmod
chown
```

### 4. Networking

Practice identifying and troubleshooting network configuration:

```bash
ip addr
ip route
ping
ss
hostname
```

### 5. Package Management

Linux Mint uses APT for managing software packages:

```bash
sudo apt update
sudo apt install <package>
sudo apt remove <package>
apt search <package>
```

### 6. Bash Scripting

Create simple scripts to automate repetitive tasks.

Example:

```bash
#!/bin/bash

echo "Linux Mint System Information"
echo "=============================="

hostname
uptime
df -h
free -h
```
